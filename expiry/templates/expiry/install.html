Add Expiry Tracker to your home screen

Open it from an icon on your phone. Use the same account and data as this website.

  • iPhone / iPad: open this site in Safari, tap Share, then Add to Home Screen. Turn on Open as Web App if shown.
  • Android: open this site in Chrome, tap the menu, then Install app or Add to Home screen.
  • Desktop: use the install icon in your browser address bar when available.

You may need to log in again after installation. Internet access is required for your private data and changes.
